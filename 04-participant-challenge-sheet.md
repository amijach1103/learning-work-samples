## Sprint 1: Google Drive (38 minutes, 25 points)

Use Claude with Google Drive to explore the Project. Find, extract, compare and synthesize.

### Challenge #1: Find the Project's docs (2 pts)

Get Claude to locate the Project's documents in Google Drive.

**Sample prompt to start with:**
> "Search my Google Drive for any documents related to the Project. What can you find?"

**What earns the points:** Claude identifies relevant Project documents by name and location.

### Challenge #2: Summarize a document (3 pts)

Get Claude to read and summarize a specific Project document.

**Sample prompt to start with:**
> "Read [document name] and give me a summary. What's this document about? What are the key points?"

**What earns the points:** a clear, accurate summary that captures the document's purpose and main content.

### Challenge #3: Extract milestones or deliverables (3 pts)

Get Claude to pull out specific structured information from the Project's docs.

**Sample prompt to start with:**
> "What were the key milestones or deliverables for the Project? Pull these from the documents you found."

**What earns the points:** a list of concrete milestones, deliverables or timeline items taken from the docs.

### Challenge #4: Compare two documents (5 pts)

Get Claude to compare two Project documents and surface differences, changes over time, or contradictions.

**Sample prompt to start with:**
> "Compare [document A] and [document B]. What changed between them? Where do they agree or disagree?"

**What earns the points:** a clear comparison that identifies meaningful differences, not just surface formatting changes.

**Tip:** this challenge rewards prompt iteration. If Claude gives a vague comparison, push it: "Be more specific. What exactly changed about [topic]?"

### Challenge #5: Identify gaps or missing info (5 pts)

Get Claude to analyze the Project's docs and identify what's missing, incomplete or unclear.

**Sample prompt to start with:**
> "Based on the Project's documents, what questions are left unanswered? What information seems to be missing or incomplete?"

**What earns the points:** specific, substantive observations about gaps, not generic "more details would help" responses.

**Tip:** give Claude context about why you're looking: "We're considering reviving the Project. What would we need to figure out that these docs don't cover?"

### Challenge #6: Synthesize a briefing (7 pts)

Get Claude to pull from multiple Project documents and create a single, coherent briefing.

**Sample prompt to start with:**
> "Using everything you've found about the Project across all the documents, create a 1-page executive briefing. Include: what the Project was, what it accomplished, why it matters, and what's unresolved."

**What earns the points:** a well-organized briefing that draws from multiple sources, not just one document. Bonus if it's something you'd actually send to a stakeholder.

**Tip:** this is the hardest Sprint 1 challenge. Give Claude specific formatting and audience instructions: "Write this for someone who's never heard of the Project and needs to decide whether to fund a revival."

## Sprint 2: Asana + Capstone (32 minutes, 22 points)

Build Project 2.0 in Asana around the lab's new strategic direction. Your Project 2.0 should serve it.

Don't worry about being an expert in the new direction. Ask Claude to help you think through the connection.

### Challenge #7: Create Project 2.0 (3 pts)

Get Claude to create a new project in Asana for Project 2.0.

**Sample prompt to start with:**
> "Create a new Asana project called 'Project 2.0 - [Your Team Name]'. This is a reimagined version of the original Project, focused on [the new direction]."

**What earns the points:** a new Asana project exists with a clear name and description.

### Challenge #8: Add sections and tasks around the new direction (4 pts)

Get Claude to organize the project with sections and fill it with tasks that reflect the new direction.

**Sample prompt to start with:**
> "Add sections to the Project 2.0 that organize the work around [the new direction]. What would the key workstreams be? Add 3-5 tasks under each section."

**What earns the points:** meaningful sections and tasks that go beyond generic project management. They should reflect thinking about how the Project serves the new direction.

**Tip:** if you're stuck on the connection, ask Claude: "How might a project like this serve [the new direction]? Give me specific initiatives we could turn into tasks."

### Challenge #9: Write a status update (3 pts)

Get Claude to write a project status update for Project 2.0 based on the work you've done.

**Sample prompt to start with:**
> "Write a status update for the Project 2.0. Summarize what we've set up so far, our approach to [the new direction], and what the next steps would be."

**What earns the points:** a status update that reads like a real project update: clear, concise, and useful to someone not in the room.

### Challenge #10: Organize by priority or timeline (5 pts)

Get Claude to prioritize or sequence the tasks in your Project 2.0.

**Sample prompt to start with:**
> "Look at the tasks in our Project 2.0. Organize them by priority: what should we tackle first and why? Consider dependencies and impact."

**What earns the points:** tasks are reorganized with a clear rationale. Claude explains the thinking behind the prioritization.

**Tip:** push for specificity: "Don't just say 'high/medium/low.' Tell me the order we should do these in and what depends on what."

### Challenge #11: Capstone, takeaway slide (7 pts)

Create a single slide (in any format: Google Slides, a doc, a screenshot, whatever works) that captures:

1. **Your Project 2.0 vision.** In 2-3 sentences, how would you redesign the Project to serve the new direction?
2. **One tedious task from your real work** that Claude could help with (not the Project: YOUR actual job)

**Sample prompt to start with:**
> "Help me create a summary slide for our Project 2.0 vision. Here's what we built: [describe your Asana project]. Summarize our vision in 2-3 compelling sentences."

**What earns the points:** both elements present. The vision is specific to your team's approach (not generic). The real-work task is concrete and actionable.

**This is worth the most points.** Don't skip it.
